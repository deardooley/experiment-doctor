## Short description

Experiment Doctor repairs a numerical decay simulation and makes the evidence inspectable. A live Vultr inference model proposes a bounded change. Fresh constrained rootless containers execute each revision; a separate trusted verifier checks the numerical outputs against the analytical solution, refinement and held-out parameters. A clean process exit cannot supply a scientific verdict. The browser shows the actual patch, trajectories, measurements, execution/cleanup, provenance and downloadable evidence.

Vultr supplies the single-VM web/control/runtime host and Serverless Inference. A narrow Agave-inspired app/job/artifact contract keeps execution replaceable without claiming compatibility with full Agave. SQLite and a leased worker fit the single-VM demo. The API, model worker, runner and web proxy use separate identities. The deliberate scope is curated scientific fixtures; arbitrary uploads, dependencies and multi-tenant hostile workloads are deferred.
